# Music

Three ~24-second loops, synthesized from scratch for this exercise (no samples), so you can use
them freely. Use them, trim them, or bring your own.

| File | Feel |
|---|---|
| `upbeat-120bpm.wav` | bright, major key |
| `driving-128bpm.wav` | punchy, minor key |
| `chill-96bpm.wav` | relaxed |
